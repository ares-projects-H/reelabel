# Reelabel branding guidelines

The MIT License in this repository covers Reelabel's software and
documentation. The Reelabel name and logo identify the official project
maintained by `ares-projects-H`; the MIT License does not grant trademark
rights or permission to imply official status, sponsorship, or endorsement.

## Uses that are welcome

You may:

- truthfully refer to Reelabel and link to the official repository;
- state that another project is based on, compatible with, or inspired by
  Reelabel;
- use the Reelabel name and logo when redistributing an unmodified official
  Reelabel release without suggesting that you created it; and
- show the name or logo in articles, reviews, tutorials, and screenshots that
  discuss the project.

## Forks and modified versions

If you distribute a modified version:

- choose a name and icon that are clearly distinguishable from Reelabel;
- state that the project is a fork or modified version and link to the official
  repository;
- do not describe it as an official Reelabel release; and
- do not use the Reelabel name, logo, or visual identity in a way that could
  reasonably imply endorsement by the Reelabel maintainer.

These guidelines are intended to prevent confusion, not to discourage honest
discussion, compatibility statements, or community development. For a use not
covered here, open a repository discussion or contact the maintainer before
publishing.
